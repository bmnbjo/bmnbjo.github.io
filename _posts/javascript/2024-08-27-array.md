### 1. **배열의 기본 개념**

- 배열은 여러 개의 값을 하나의 변수에 저장하는 자료 구조임.
- 배열의 원소는 0부터 시작하는 인덱스로 접근함.
- 배열은 숫자, 문자열, 객체 등 다양한 데이터 타입을 포함할 수 있음.

```
let arr = [11, 22, 'text', true];
console.log(arr[0]); // 11
console.log(arr.length); // 4
```

------

### 2. **배열의 기본 조작**

#### (1) **값 추가**

- `push`: 배열 끝에 요소 추가.
- `unshift`: 배열 앞에 요소 추가.

```
let arr = [1, 2, 3];
arr.push(4); // [1, 2, 3, 4]
arr.unshift(0); // [0, 1, 2, 3, 4]
```

#### (2) **값 삭제**

- `pop`: 배열 끝 요소 삭제 및 반환.
- `shift`: 배열 앞 요소 삭제 및 반환.
- `delete`: 특정 인덱스의 값 삭제 (undefined로 남음).

```
let arr = [1, 2, 3];
arr.pop(); // [1, 2]
arr.shift(); // [2]
delete arr[1]; // [undefined]
```

### <`delete` 키워드의 특징>

- 특정 **인덱스의 값**을 삭제하지만, 배열의 **길이**에는 영향을 미치지 않음.
- 삭제된 자리에는 `undefined`가 남음.
- 배열의 구조는 유지되지만, 요소 값이 삭제됨.

------

### `delete`의 예시

```
let arr = [1, 2, 3];

// 배열 출력
console.log(arr); // [1, 2, 3]

// 배열의 첫 번째 요소 삭제
delete arr[0];

// 결과 확인
console.log(arr);       // [undefined, 2, 3]
console.log(arr.length); // 3 (길이는 그대로)

// 두 번째 요소 삭제
delete arr[1];
console.log(arr); // [undefined, undefined, 3]

// 배열 반복
arr.forEach((value, index) => {
    console.log(`Index ${index}:`, value); 
});
// Index 0: undefined
// Index 1: undefined
// Index 2: 3
```



#### (3) **중간 조작**

- `splice`: 중간에 값 삽입/삭제/교체.

```
array.splice(startIndex, deleteCount, item1, item2, ...);
```

- **`startIndex`**: 시작 인덱스 (수정 작업이 시작될 위치).

- `deleteCount`

  : 제거할 요소의 개수.

  - 0을 지정하면 삭제 없이 요소를 삽입만 함.

- **`item1, item2, ...`**: 배열에 추가할 요소(옵션).

```
let arr = [1, 2, 3, 4];
arr.splice(1, 2, 99, 100); // [1, 99, 100, 4]
```

### 3. **배열 탐색**

#### (1) **원소 존재 확인**

- `includes`: 값 포함 여부 반환.

```
[1, 2, 3].includes(2); // true
```

#### (2) **값의 위치 확인**

- `indexOf`: 첫 번째로 일치하는 값의 인덱스 반환.
- `lastIndexOf`: 마지막으로 일치하는 값의 인덱스 반환.

```
[1, 2, 3, 2].indexOf(2); // 1
[1, 2, 3, 2].lastIndexOf(2); // 3
```

### 4. **배열 반복**

- `for...in`
  - 배열의 인덱스를 순회.
  -  객체의 속성을 순회할 때 주로 사용.
  - 배열에서는 실제로 사용이 권장되지 않음(객체처럼 작동하며 예상치 못한 결과가 발생할 수 있음).
- `for...of`
  - 배열의 값을 순회.
  -  배열, 문자열, 맵(Map), 셋(Set)과 같은 **이터러블(iterable)** 객체를 순회 가능.
  -  인덱스가 필요 없는 경우 적합.
- `for...each`
  - **콜백 함수**를 사용하여 배열의 각 요소를 순회.
  - 인덱스와 배열 전체를 참조할 수 있음.
  - `break`나 `continue`를 사용할 수 없음.

```
arr.forEach((value, index) => {
    console.log(`Index ${index}: Value ${value}`);
});
// 출력:
// Index 0: Value 10
// Index 1: Value 20
// Index 2: Value 30
// Index 3: Value 40
```

### 5. **배열 복사**

#### (1) 얕은 복사(주소 공유)

- 배열을 직접 대입하면 참조 주소만 복사.

```
let arr1 = [1, 2, 3];
let arr2 = arr1; // 같은 주소 공유
arr2[0] = 99; // arr1[0]도 99로 변경됨
```

#### (2) 깊은 복사(새로운 공간)

- `slice` 또는 `spread operator`로 새로운 배열 생성.

```
let arr1 = [1, 2, 3];
let arr2 = arr1.slice();
let arr3 = [...arr1];
```



### **얕은 복사 vs 깊은 복사 차이 요약**

| 특징            | 얕은 복사                        | 깊은 복사                          |
| --------------- | -------------------------------- | ---------------------------------- |
| **메모리 공유** | 원본과 복사본이 같은 주소를 공유 | 복사본이 새로운 메모리 주소를 가짐 |
| **독립성**      | 복사본 수정 시 원본이 변경됨     | 복사본 수정 시 원본은 영향 없음    |
| **복사 방식**   | 참조(주소 복사)                  | 값 자체 복사                       |
| **예시 메서드** | 직접 대입 `arr2 = arr1`          | `slice()`, `spread (...)`          |

### 6. **배열과 문자열 변환**

- `split`: 문자열 → 배열 변환.
- `join`: 배열 → 문자열 변환.

```
let str = "a,b,c";
let arr = str.split(","); // ['a', 'b', 'c']
let newStr = arr.join("-"); // "a-b-c"
```

------

### 7. **배열 결합**

- `concat`: 두 배열을 결합.

```
let arr1 = [1, 2];
let arr2 = [3, 4];
let combined = arr1.concat(arr2); // [1, 2, 3, 4]
```

------

### 8. **정렬**

- `sort`: 배열 정렬.
- `reverse`: 배열 뒤집기.

```
let arr = [3, 1, 2];
arr.sort(); // [1, 2, 3]
arr.reverse(); // [3, 2, 1]
```

------

### 9. **고급 배열 조작**

#### (1) **조건 필터링**

- `filter`: 조건에 맞는 요소만 반환.

```
let arr = [1, 2, 3, 4];
let even = arr.filter(n => n % 2 === 0); // [2, 4]
```

#### (2) **값 변환**

- `map`: 배열의 각 요소를 변환해 새로운 배열 반환.

```
let arr = [1, 2, 3];
let squared = arr.map(n => n ** 2); // [1, 4, 9]
```

#### (3) **값 누적**

- `reduce`: 모든 요소를 하나의 값으로 누적.

```
let arr = [1, 2, 3];
let sum = arr.reduce((acc, curr) => acc + curr, 0); // 6
```



### <**`reduce` 메서드 사용법**>

`reduce`는 배열의 모든 요소를 순회하며, **하나의 누적된 값**으로 축약(reduce)하는 데 사용됨.
주로 배열의 합계, 평균, 곱셈, 객체 변환 등 다양한 연산에 사용됨.

------

### **문법**

```
array.reduce(callback, initialValue);
```

- `callback`: 배열의 각 요소에 대해 실행되는 함수.
  - 매개변수:
    1. **`acc`** (accumulator): 이전 콜백 실행의 반환값. 누적된 값.
    2. **`curr`** (current): 현재 처리 중인 배열의 요소.
    3. **`index`** (optional): 현재 처리 중인 요소의 인덱스.
    4. **`array`** (optional): `reduce`가 호출된 배열.
- **`initialValue`**: 초기값. 생략하면 배열의 첫 번째 요소가 초기값으로 사용됨.



### **예제: 배열의 합 계산**

```
let arr = [1, 2, 3];

// 초기값 0으로 설정
let sum = arr.reduce((acc, curr) => acc + curr, 0);

console.log(sum); // 6

// 위의 경우 0 생략하고 arr.reduce((acc, curr) => acc + curr); 이어도 동일한 결과
```



### **매개변수 규칙**

**순서는 반드시 지켜야 함.**

- 중간의 매개변수를 건너뛰고 특정 매개변수만 직접적으로 사용할 수 없음.

**사용하지 않는 매개변수는 `_` 또는 `unused`로 표시해 무시.**

- 이 관행은 코드의 가독성을 높이고 의도를 명확히 전달함.

**뒤쪽 매개변수는 생략 가능.**

- 필요한 매개변수만 사용하면 됨.
