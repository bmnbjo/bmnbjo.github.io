###  **for(반복문)**

- JavaScript의 반복문(`for`, `while`, `do~while`)을 활용하면 특정 작업을 반복적으로 처리할 수 있음. 특히 `break`, `continue`, 레이블(label)을 사용해 흐름을 세밀하게 제어 가능.

**기본 반복문**:

```
for (let i = 1; i <= 5; i++) {
    console.log(`현재 숫자: ${i}`);
}
```

**레이블과 break**:

```
OUTER: for (let i = 1; i <= 3; i++) {
    for (let j = 1; j <= 3; j++) {
        if (j === 2) break OUTER; // 레이블로 외부 루프 종료
        console.log(`i: ${i}, j: ${j}`);
    }
}
```













### **while과 do~while의 차이**

#### 개념

- `while`: 조건이 참일 때만 실행.
- `do~while`: 조건과 상관없이 최소 한 번 실행.
