### **1. if문이란?**

`if`문은 조건을 평가하고, 그 결과에 따라 코드 블록을 실행하는 제어문이다. 가장 기본적인 조건문으로, 프로그램의 흐름을 제어하는 핵심 역할을 한다.

------

### **2. if문의 기본 구조**

```
if (조건) {
    // 조건이 참(true)일 때 실행할 코드
}
```

- **조건**: `true` 또는 `false`로 평가될 수 있는 표현식.
- 조건이 **참(true)**이면 코드 블록 실행, **거짓(false)**이면 실행되지 않음.

------

### **3. if-else문**

조건이 참일 때와 거짓일 때 각각 다른 코드를 실행할 수 있음.

```
if (조건) {
    // 조건이 참일 때 실행할 코드
} else {
    // 조건이 거짓일 때 실행할 코드
}
```

------

### **4. if-else if-else문**

여러 조건을 평가하여 해당 조건을 만족하는 블록만 실행.

```
if (조건1) {
    // 조건1이 참일 때 실행
} else if (조건2) {
    // 조건2가 참일 때 실행
} else {
    // 위 조건들이 모두 거짓일 때 실행
}
```

------

### **5. 삼항 연산자와의 비교**

삼항 연산자는 간단한 조건문을 한 줄로 표현할 때 사용.

```
// if문
if (조건) {
    결과 = "참";
} else {
    결과 = "거짓";
}

// 삼항 연산자
결과 = 조건 ? "참" : "거짓";
```
