### **1. `switch`문의 정의**

- `switch`문은 **하나의 값**에 대해 여러 조건을 검사하고, 해당하는 조건의 코드를 실행하는 제어문.
- 조건이 많을 때 `if-else if`문보다 **가독성이 높고 깔끔**하게 작성 가능.

------

### **2. `switch`문의 기본 구조**

```
switch (표현식) {
    case 값1:
        // 값1일 때 실행할 코드
        break;
    case 값2:
        // 값2일 때 실행할 코드
        break;
    default:
        // 위의 조건에 모두 해당하지 않을 때 실행할 코드
}
```

- **표현식**: 조건에 따라 검사할 값. 숫자, 문자열, 불리언 등 다양한 타입 사용 가능.
- **`case`**: 특정 값에 대한 조건을 정의.
- **`break`**: 현재 실행 중인 `case` 블록을 빠져나감. 없으면 다음 `case`도 실행됨(폴스루 발생).
- **`default`**: 위의 `case` 조건에 해당하지 않을 때 실행.

------

### **3. 주요 특징**

1. **값 기반 분기**:
   - `switch`문은 표현식의 값과 `case`에 정의된 값을 비교하여 실행.
   - 숫자, 문자열, 불리언, 심지어 소수점 값도 비교 가능.
2. **순서 무관**:
   - `case`의 순서는 중요하지 않음. 일치하는 값을 찾으면 해당 블록을 실행.
3. **폴스루(Fall-Through)**:
   - `break`문이 없으면 다음 `case` 블록도 실행됨.
   - 의도적인 폴스루는 주의 깊게 작성해야 함.
4. **`default` 사용**:
   - `if-else`의 `else`처럼, 어떤 `case`에도 해당하지 않을 때 실행.

------

### **4. 실전 예제와 설명**

#### **1) 기본적인 값 비교**

```
let grade = "과장";

switch (grade) {
    case "부장":
        console.log("보너스: 50%");
        break;
    case "과장":
        console.log("보너스: 30%");
        break;
    case "대리":
        console.log("보너스: 20%");
        break;
    default:
        console.log("보너스 없음");
}
```

- 동작
  - `grade`가 "과장"이므로 "보너스: 30%" 출력.
  - 다른 값에는 해당하지 않으면 `default` 실행.

------

#### **2) 숫자 값과 폴스루**

```
switch (20) {
    case 10:
        console.log("10입니다.");
    case 20:
        console.log("20입니다."); // 실행
    case 30:
        console.log("30입니다."); // 실행 (폴스루 발생)
        break;
    default:
        console.log("기본값입니다.");
}
```

- 폴스루 발생
  - `case 20`에서 시작해 `break`가 없으므로 `case 30`도 실행.

------

#### **3) 소수점, 불리언, 문자열 비교**

```
switch ("아메리카노") {
    case "아메리카노":
        console.log("2000원");
        break;
    case "아시아노":
        console.log("3000원");
        break;
    default:
        console.log("없는 메뉴입니다.");
}
```

- 다양한 값
  - `case` 값으로 문자열, 숫자, 소수점, 불리언 등 사용 가능.

------

#### **4) `default` 활용**

```
let number = 999;

switch (number) {
    case 10:
        console.log("10입니다.");
        break;
    case 50:
        console.log("50입니다.");
        break;
    default:
        console.log("기본값입니다."); // 999는 해당 없음
}
```

- `default`는 모든 `case`에 해당하지 않을 때 실행.
